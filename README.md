# dsh-token-cost

轻量、简洁、无需访问本地 API Key 和网络的 DeepSeek Harness 费用统计插件。根据当前会话的 Token 用量和峰谷时价格计算。在 DSH 自带「Token 用量」胶囊旁显示当前会话的费用，点击后显示详细信息。

## 功能

- 显示当前会话的费用总额。通过 Token 用量计算价格，不计入查询接口调用等非 Token 价格。
- 详细信息显示缓存命中率、未缓存输入、缓存读取、缓存写入、输出各项的 Token 数与费用。
- 高峰 / 空闲时段提示：胶囊图标随当前时段切换，高峰为太阳，空闲为月亮。
- 未匹配官方价格的模型显示「未定价」警告。
- 无用量时自动隐藏。

## 安装

要求：DSH Web profile 已启用 `sessionProjections` 服务（默认 Web 组合包含）。

1. 克隆本仓库到本地任意目录。
2. 在 DSH Web UI 的插件管理器中安装本地 bundle，选择仓库目录。
3. 刷新页面。

插件包名为 `dsh-token-cost`，bundle 行 id 为 `token-cost`。没有构建步骤、安装脚本或外部 npm 依赖，可以直接以本地目录安装。

## 使用

- 有 Token 用量时，输入框下方会出现费用胶囊；无用量时隐藏。
- 点击胶囊查看明细；`Escape` 或点击外部关闭。
- 胶囊图标表示当前时段：太阳为高峰，月亮为空闲。
- 悬停或读屏文本会附带「高峰时段」/「空闲时段」。

## 计价口径

当前价格更新时间：2026-11-02。价格来源：[DeepSeek 模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

单位：人民币元 / 百万 tokens。

| 模型 | 输入（缓存命中） | 输入（缓存未命中） | 输出 |
|---|---|---|---|
| `deepseek-flash` | 空闲 0.02 / 高峰 0.04 | 空闲 1 / 高峰 2 | 空闲 4 / 高峰 8 |
| `deepseek-v4-pro` | 空闲 0.15 / 高峰 0.30 | 空闲 4.5 / 高峰 9 | 空闲 13.5 / 高峰 27 |

峰谷规则（北京时间，UTC+8）：

- 高峰：周一至周五 09:00–12:00、14:00–18:00。
- 空闲：其余时段、周末和法定节假日全天。
- 2026 法定节假日依据[国务院办公厅通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)：01-01～01-03、02-15～02-23、04-04～04-06、05-01～05-05、06-19～06-21、09-25～09-27、10-01～10-07。
- 2027 法定节假日依据[国务院办公厅通知](https://www.gov.cn/zhengce/content/202611/content_7085101.htm)：01-01～01-03、02-05～02-13、04-03～04-05、05-01～05-05、06-09、09-15、10-01～10-07。
- 日期自带年份，跨年后自动使用新一年度的表；未收录年份按普通工作日/周末规则估算。
- 调休上班的周末仍按周末（空闲）计价，因为官方规则以周一至周五为高峰。
- 分类使用用量事件的 `event.time`（模型调用结算时刻）；无法解析的时间按高峰保守处理。

计算公式：

```text
cost = (input     × cacheMissRate
      + cacheRead × cacheHitRate
      + cacheWrite × (cacheWriteRate ?? cacheMissRate)
      + output    × outputRate) / 1_000_000
```

`output` 已包含推理 tokens，不重复累加。DeepSeek 通常不上报缓存写入；若上报，按缓存未命中费率兜底。仅供估算。

## 更新价格表

编辑 [`pricing.js`](pricing.js)：

- `MODELS`：模型与高峰/空闲费率。
- `MODEL_ALIASES`：旧模型名映射。
- `HOLIDAY_RANGES_BY_YEAR`：按年份分组的法定节假日区间；新增年份时增加一个年份键，跨年自动生效。

## 限制

- 只统计当前 Session；子代理各自独立，不汇总到父会话。
- 不包含 Search / Fetch 等非 Token 费用。
- 历史会话统一按当前内置价格表重算，不是历史账单。
- 已内置 2026–2027 年法定节假日；2028 年及以后需在国务院通知发布后补充 `HOLIDAY_RANGES_BY_YEAR`，未收录年份按普通工作日/周末规则估算。
- 价格按模型 ID 匹配；如果通过第三方网关使用同名模型，仍按 DeepSeek 官方列表价估算。
- 不做余额、预算、Coding Plan、价格在线同步或全局历史统计。
